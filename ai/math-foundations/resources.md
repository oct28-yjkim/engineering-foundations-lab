# 공식 무료 자료를 골라 읽는 방법

[시작 안내](README.md) · [진단과 보충 경로](diagnostic.md)

2026-10-05 기준 대학 또는 저자 공식 페이지를 확인했습니다. **각 영역의 첫 자료 하나 → 필요할 때 깊이 확장 하나** 순서로 사용합니다. 아래 시간은 지정한 작은 부분을 읽고 직접 계산할 시간의 대략적인 예산이며 강의 전체 길이·완주 시간·숙련 보장이 아닙니다.

모두 공개적으로 무료 열람 가능한 학습 자료를 안내합니다. 대체로 영어이며 영상 자막이나 번역의 존재·정확성은 보장하지 않습니다. 수료증·학점·유료 강좌 등록을 권하거나 포함하지 않습니다. 이 저장소는 외부 PDF·영상·데이터를 자동 다운로드하지 않습니다. 링크를 열지 않아도 로컬 강의·문제·LAB을 사용할 수 있습니다.

<a id="vectors"></a>
## 벡터·행렬

- **첫 자료 — [Stanford CS229 선형대수 복습 PDF](https://cs229.stanford.edu/section/cs229-linalg.pdf).** §1 표기, §2.1~2.3의 벡터/행렬 곱, §3.2 전치, §3.5 길이부터 읽습니다. 60~90분 동안 식 하나마다 입력·출력 크기를 옆에 적고 2×2 숫자로 바꿔 계산합니다. 처음부터 determinant나 matrix calculus까지 읽지 않습니다.
- **깊이 확장 — [MIT 18.06 공식 강의 목록](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/video_galleries/video-lectures/).** 강의 14~16 중 15의 투영부터 시작하고 직교가 낯설면 14, 최소제곱으로 연결하려면 16을 고릅니다. 2~3시간 예산으로 그림, 투영된 벡터, 남는 벡터를 따로 그립니다. 영상 시청 시간보다 재계산 시간을 우선합니다.

결과물: `X(2×3)w(3×1)`의 크기, 내적과 원소별 곱의 차이, 투영의 잔차가 기준 방향에 직각이라는 검산을 남깁니다. [V1~V3와 R01~R03](lessons/01-vectors-matrices.md)으로 돌아옵니다.

<a id="derivatives"></a>
## 미분·연쇄법칙

- **첫 자료 — [MIT 18.01SC 미분 기초](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/pages/1.-differentiation/part-a-definition-and-basic-rules/).** Session 1, 6, 11에서 변화율, 미분 계산, 합성함수의 연결을 순서대로 봅니다. 2~3시간 예산으로 `입력 → 중간값 → 손실` 세 상자를 그리고 상자 사이의 미분을 적습니다. 적분 단원까지 먼저 완주할 필요는 없습니다.
- **깊이 확장 — [MIT 18.02SC 연쇄법칙과 gradient](https://ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/2.-partial-derivatives/part-b-chain-rule-gradient-and-directional-derivatives/).** Session 32, 35, 필요하면 38을 읽고 `w`만 바꿀 때와 `b`만 바꿀 때의 기울기를 구분합니다. 2~3시간 예산으로 두 parameter의 gradient를 손계산합니다. 여러 변수가 처음이면 본 강의 D3를 먼저 읽습니다.

결과물: 합성함수의 안쪽 미분, 같은 parameter가 두 경로에 나타날 때의 합산, batch 평균의 분모를 표시합니다. [D1~D4와 R04~R06](lessons/02-derivatives-chain-rule.md)으로 돌아옵니다.

<a id="probability"></a>
## 확률·통계

- **첫 자료 — [Stanford CS229 확률 복습 PDF](https://cs229.stanford.edu/section/cs229-prob.pdf).** §1.1의 조건부 확률, §2.4의 기댓값, §2.5의 분산을 봅니다. 60~90분 동안 확률을 가상의 1,000개 개수 표로 바꾸고 어떤 집단을 분모로 삼았는지 적습니다. 그다음 본 강의 P3에서 정답 확률의 로그로 연결합니다.
- **깊이 확장 — [Harvard Stat110 공식 영상 안내](https://stat110.hsites.harvard.edu/youtube).** 강의 4~5의 조건부 확률부터 보고 평균이 막히면 9, 분산이 막히면 12를 선택합니다. 한 번에 두 강의 이내, 2~3시간 예산으로 본 강의의 부품 검사 표를 새 숫자로 다시 만듭니다. [공식 강좌 홈](https://stat110.hsites.harvard.edu/)은 교재와 다른 공개 자료의 출발점입니다.

결과물: `P(A|B)`와 `P(B|A)`의 분모 차이, 분포 분산과 표본분산, 확률·NLL·accuracy의 구분을 적습니다. [P1~P3와 R07~R09](lessons/03-probability-statistics.md)으로 돌아옵니다. Stat110 전체 과정은 초급 산술 강좌가 아니므로 당장 전부 이해할 필요는 없습니다.

<a id="optimization"></a>
## 최적화·수치 계산

- **첫 자료 — [Mathematics for Machine Learning 저자 공식 사이트](https://mml-book.github.io/).** 무료 본문의 7장 중 gradient descent를 다루는 부분을 선택합니다. 기울기 표기가 막히면 5장의 미분 부분만 먼저 되돌아봅니다. 90~120분 예산으로 `현재값 - 학습률 × 기울기`를 숫자로 세 번 적용합니다. 제약 최적화 전체를 선행하지 않습니다.
- **깊이 확장 — [Stanford CS229 선형대수 복습 PDF](https://cs229.stanford.edu/section/cs229-linalg.pdf).** §3.11의 이차식과 §4.2~4.3의 이차식 미분을 골라 봅니다. 90~120분 동안 `x²+25y²`의 축별 기울기가 왜 다른지 설명합니다. 행렬로 된 Hessian이 아직 어렵다면 본 강의 O2의 대각 이차식까지만 계산합니다.

결과물: 작은/큰 학습률의 한 step 비교, scale을 바꿨을 때의 계산, log-sum-exp의 최댓값 빼기를 남깁니다. [O1~O3와 R10~R12](lessons/04-optimization-numerics.md)로 돌아옵니다. 위 교재가 이 저장소의 모든 수치 안정성 반례나 LAB 구현을 제공한다는 뜻은 아닙니다.

## 한 권으로 다시 연결하고 싶다면

[MML 저자 공식 사이트](https://mml-book.github.io/)에서 공개한 목차를 기준으로 한 **선택적 재방문 지도**입니다. 위의 첫 자료에 추가로 모두 읽어야 하는 숙제가 아닙니다. 본문은 영어이며 저자는 Marc Peter Deisenroth, A. Aldo Faisal, Cheng Soon Ong입니다.

| 장 | 지금 필요한 내용만 찾기 | 연결할 저장소 강의 |
| --- | --- | --- |
| 2장 | 벡터·행렬 표기와 선형 연산 | V1~V2 |
| 3장 | 내적·길이·직교·투영의 기하학 | V3 |
| 4장 | 행렬 분해가 표현/계산을 바꾸는 이유; 첫 순환 뒤 선택 | ML의 PCA, O2의 축별 곡률 확장 |
| 5장 | 함수의 변화율, 여러 변수와 연쇄법칙 | D1~D3 |
| 6장 | 조건부 확률과 분포의 평균·분산 | P1~P2 |
| 7장 | 목적함수를 줄이는 반복 계산 | O1~O2 |

공식 사이트에서 무료 PDF 제공과 2~7장 목차를 확인했습니다. 이번 자료 확인 환경에서는 전체 PDF가 크기 제한으로 열리지 않아 본문의 상세 절 번호나 최신 PDF 페이지 번호까지 대조하지 않았습니다. 따라서 장과 주제 이름으로 안내하며 확인하지 않은 문제 번호는 지정하지 않습니다. 강사용 해답집은 별도 요청 절차가 있으므로 공개 무료 해설이라고 안내하지 않습니다. 이 저장소 재검산 문제에는 자체 해설이 있습니다.

## 읽기보다 먼저 남길 기록

외부 자료 한 묶음마다 `읽은 절/강의 번호`, `내 말로 쓴 정의`, `직접 계산한 숫자 예제`, `아직 설명 못 하는 질문 하나`를 남깁니다. 페이지 수나 시청 시간을 이해의 증거로 삼지 않습니다. 외부 원문의 큰 표·긴 문단·문제집 전체를 저장소에 복사하지 말고 링크와 자신의 짧은 설명을 사용합니다.
