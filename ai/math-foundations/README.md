# ML·DL·LLM을 위한 수학 보충

[AI 기초 안내](../foundations.md) · [ML → DL → LLM 경로](../ml-dl-llm-roadmap.md)

수학을 잘해야 시작할 수 있다는 뜻이 아닙니다. 논문의 식을 만났을 때 **기호의 뜻을 말하고, 작은 숫자로 계산하고, 코드의 결과와 비교할 수 있게** 만드는 보충 과정입니다. 처음부터 증명을 모두 외우거나 대학 수학 전 과정을 끝낼 필요는 없습니다.

여기서는 벡터·행렬, 미분, 확률·통계, 최적화·수치 계산 네 영역을 다룹니다. 어려운 식을 건너뛰는 대신 두세 개 숫자로 줄여서 확인합니다. 수학의 모든 분야나 ML·DL·LLM 전체 선수 조건을 대신하는 과정은 아닙니다.

## 처음 시작하는 순서

1. [12문항 진단](diagnostic.md)을 30~60분 동안 풉니다. 모르는 것은 표시만 하고 넘어갑니다. 총점보다 어느 영역에서 막혔는지가 중요합니다.
2. 진단표에서 해당 강의 절로 이동합니다. 본문의 손계산 예제를 먼저 직접 다시 계산합니다.
3. 여전히 이해가 어렵다면 [공식 무료 자료](resources.md)의 **첫 자료**에서 지정된 부분만 읽습니다. 영어 원문을 한 번에 완독할 필요는 없습니다.
4. 강의 끝의 **재검산 R01~R12**를 해설을 닫은 상태로 풉니다. 진단과 숫자가 달라서 정답 암기만으로 통과하지 않습니다.
5. 같은 개념을 [표준 라이브러리 LAB](labs/README.md)의 다른 숫자와 실패 사례로 확인합니다. 실행 성공과 직접 설명할 수 있는지는 별개의 기준입니다.

## 4주·48시간 빠른 순환

주 12시간은 계획을 세우기 위한 예시입니다. 처음 진단하고 약한 부분을 발견하는 **첫 순환 예산**이지, 4주 뒤 수학을 완성한다는 약속이 아닙니다. 기존 ML·DL·LLM 과정의 주수에 자동 합산하거나 기존 일정을 바꾸지 않습니다.

| 주차 | 12시간 배분 예시 | 남길 결과 |
| --- | --- | --- |
| 1주 | 진단 1h + 벡터·행렬 설명/손계산 6h + 자료 읽기 3h + 재검산/LAB 2h | 행렬의 입력·출력 크기, 내적과 투영 설명 |
| 2주 | 미분 설명/손계산 6h + 자료 읽기 3h + 재검산/LAB 3h | 계산 그래프, 각 경로의 미분과 합산 |
| 3주 | 확률·통계 설명/손계산 6h + 자료 읽기 3h + 재검산/LAB 3h | 분모를 포함한 Bayes 표, 분산과 NLL 구분 |
| 4주 | 최적화 설명/자료/실습 8h + 네 영역 재진단·말로 설명 4h | 한 번의 업데이트, 발산 반례, 안정적인 로그 계산 |

부족한 영역마다 **추가 1~2주(주 12h라면 12~24h)**를 잡고 같은 순환을 반복할 수 있습니다. 더 오래 필요할 수도 있습니다. 자료를 많이 읽는 것보다 새 숫자로 계산하고 오류 이유를 설명할 수 있는지를 봅니다. 분수·음수·거듭제곱 계산부터 막히면 그 부분부터 보충하고 속도를 줄입니다.

## 네 강의와 실험 연결

| 강의 | 진단 → 재검산 | 제공 LAB 선택지 | 다음 과정에서 쓰는 곳 |
| --- | --- | --- | --- |
| [벡터·행렬](lessons/01-vectors-matrices.md) | Q01~03 → R01~03 | `vectors` | 선형회귀의 `Xw`, PCA, embedding·attention의 크기 |
| [미분·연쇄법칙](lessons/02-derivatives-chain-rule.md) | Q04~06 → R04~06 | `derivatives` | loss의 gradient, 역전파, 공유 parameter |
| [확률·통계](lessons/03-probability-statistics.md) | Q07~09 → R07~09 | `probability` | 불균형 데이터, 분산, 분류/언어모델의 NLL |
| [최적화·수치 계산](lessons/04-optimization-numerics.md) | Q10~12 → R10~12 | `optimization` | learning rate, 입력 scale, 안정적인 softmax |

저장소 루트에서 Python 3.10 이상으로 실행합니다.

```text
python -B ai/math-foundations/labs/lab.py --lab all
python -B -m unittest discover -s ai/math-foundations/labs -p test_lab.py -v
```

LAB은 CPU·오프라인·Python 표준 라이브러리만 사용합니다. GPU, API 키, Docker, 패키지 설치나 외부 자료 다운로드가 필요하지 않습니다. 외부 강의는 사용자가 선택해 브라우저에서 열어 보는 자료입니다. 개별 실행과 실제 제공 범위는 [LAB 안내](labs/README.md)를 확인합니다.

## 무엇을 할 수 있으면 다음 단계로 가나요?

- 식에 등장한 값의 의미와 크기를 말한다. 예: `X`의 한 행이 한 sample이라는 약속을 설명한다.
- 새로운 작은 숫자로 중간 계산을 남기고 답을 구한다. 해설을 보고 베끼는 것은 재검산이 아니다.
- 코드 출력과 다르면 부호, 분모, 평균, shape, 로그 밑, 학습률 중 무엇이 다른지 좁힌다.
- 한 가지 반례를 설명한다. 예: 양성이 나왔다고 실제 양성 확률이 검사 민감도와 같지는 않다.
- 작은 식 검증과 실제 모델 학습, 일반화 성능 검증을 구분한다. LAB의 통과를 논문 재현이라고 부르지 않는다.

막힌 영역이 있으면 그 영역을 보충하면서 [ML 일반화](../ml-paper-lab/lessons/01-generalization.md)처럼 계산 부담이 적은 부분을 함께 읽어도 됩니다. [DL 역전파](../dl-paper-lab/lessons/01-backprop-optimization.md) 전에는 미분·최적화, [LLM 구조](../llm-paper-lab/lessons/01-transformers-scaling.md) 전에는 행렬 크기·로그 확률을 다시 점검합니다. 본 과정 통과만으로 뒤 과정의 진입 관문이 자동 통과되는 것은 아닙니다.
