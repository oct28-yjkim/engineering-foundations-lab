# 03. 확률·통계: 분모와 질문을 먼저 정하기

[시작 안내](../README.md) · [진단 Q07~Q09](../diagnostic.md) · [공식 자료](../resources.md#probability)

확률 계산에서 먼저 물을 것은 “어떤 경우 중에서 얼마인가?”입니다. 이 강의의 검사는 가상의 부품 검사이며 실제 산업·의료 검사 성능을 나타내지 않습니다.

<a id="p1"></a>
## P1. 조건부 확률과 Bayes

`P(A)`는 A가 일어날 확률입니다. `P(A|B)`는 **B가 일어났다는 조건 아래** A일 확률입니다. 세로선 뒤의 B가 계산 대상으로 삼을 집단을 정합니다. `P(B)>0`일 때 `P(A|B)=P(A와 B)/P(B)`입니다.

가상의 부품 중 5%가 불량입니다. 불량 부품의 80%에 경고가 뜨고 정상 부품의 10%에도 경고가 뜹니다. 1,000개를 비율대로 나누어 보겠습니다. 아래 개수는 확률을 이해하기 위한 계산상 개수이며 매번 검사하면 반드시 이렇게 나온다는 뜻은 아닙니다.

| 부품 상태 | 전체 | 경고 | 경고 없음 |
| --- | ---: | ---: | ---: |
| 불량 | 50 | 40 | 10 |
| 정상 | 950 | 95 | 855 |
| 합계 | 1,000 | 135 | 865 |

`P(경고|불량)=40/50=0.8`이지만, 우리가 경고를 보고 알고 싶은 것은 `P(불량|경고)=40/135=8/27≈0.2963`입니다. 두 확률은 분모가 다릅니다.

```text
P(불량|경고)
= P(경고|불량)P(불량)
  / [P(경고|불량)P(불량) + P(경고|정상)P(정상)]
= 0.8×0.05 / (0.8×0.05 + 0.1×0.95)
```

이것이 여기서 사용하는 Bayes 계산입니다. 불량 비율을 무시하면 경고의 의미를 크게 오해할 수 있습니다. 사건이 독립이라면 조건을 알아도 확률이 달라지지 않지만, 임의로 독립이라고 가정해서 조건부 확률을 지우면 안 됩니다.

<a id="p2"></a>
## P2. 평균과 분산: 질문에 따라 분모가 달라진다

평균은 중심 위치, 분산은 평균에서 얼마나 퍼져 있는지 나타냅니다. 각 값이 같은 확률이면 단순 평균을 쓰고, 확률이 다르면 확률을 곱한 가중 평균을 씁니다. 확률 가중치의 합은 1이어야 합니다.

```text
평균 μ = Σᵢ pᵢxᵢ
분산 Var(X) = Σᵢ pᵢ(xᵢ-μ)²
```

0과 2를 각각 확률 1/2로 뽑는 분포에서는 평균이 1입니다. 평균과의 차이는 -1과 1, 제곱은 둘 다 1이므로 분산은 1입니다. 원래 값의 제곱 평균 2에서 평균의 제곱 1을 빼도 1입니다. `E[X²]`와 `(E[X])²`는 다른 계산입니다.

같은 `[0,2]`가 더 큰 모집단에서 얻은 독립 관측 두 개라면, 모집단 분산을 추정하는 통상적인 **불편 표본분산**은 제곱 편차 합을 `n-1`로 나눕니다. 여기서는 `2/(2-1)=2`입니다. 전체 분포를 알고 계산한 분산 1과 질문 자체가 다릅니다. n=1에서는 이 표본분산 식을 사용할 수 없습니다.

`n-1`이 모든 상황에 맞는 마법의 규칙은 아닙니다. 이 불편성 설명은 같은 분포에서 독립적으로 얻은 표본, 유한한 분산 등의 조건을 전제로 합니다. 시계열처럼 관측이 서로 연결되면 추정과 불확실성 해석을 더 검토해야 합니다. 분산의 단위는 원래 값의 단위를 제곱한 것이고, 표준편차는 분산의 제곱근입니다.

<a id="p3"></a>
## P3. 로그 확률, NLL, perplexity

확률은 0~1 사이입니다. 정답에 확률 0.8을 준 예측과 0.2를 준 예측을 비교할 때, 정답의 음의 로그 확률을 손실로 사용할 수 있습니다. 이를 NLL이라고 부릅니다.

```text
한 정답의 NLL = -ln(p_true)
p_true=0.8 → 약 0.2231
p_true=0.2 → 약 1.6094
```

여기서 `ln`은 자연로그입니다. `ln(ab)=ln(a)+ln(b)`, `ln(1)=0`이고, `exp`는 자연로그를 되돌리는 함수입니다. 여러 확률을 계속 곱하면 아주 작은 수가 되지만 로그를 사용하면 합으로 다룰 수 있습니다. 정답 확률이 높을수록 NLL은 작습니다. 확률 0의 로그는 유한하지 않으므로 입력 계약이나 안정적인 logits 계산을 확인해야 합니다. 임의의 작은 값으로 바꾸면 원래 계산이 변경됩니다.

언어모델은 각 정답 token을 **이전 문맥에 조건부로** 예측합니다. 연속 token 확률의 곱을 조건부 확률의 연쇄로 쓸 수 있으며, token들이 서로 독립이라는 주장을 하는 것이 아닙니다. NLL을 token 수로 나눈 평균을 사용했다면:

```text
평균 NLL = -(1/n)Σᵢ ln(p_true,i)
perplexity = exp(평균 NLL)
```

두 정답 확률이 1/2과 1/8이면 평균 NLL은 `(ln2+ln8)/2=ln4`, perplexity는 4입니다. 확률의 산술 평균 `5/16`에 먼저 로그를 취하는 것과 다릅니다. 자연로그 대신 다른 밑을 사용했다면 되돌리는 지수의 밑도 맞아야 합니다.

accuracy는 보통 가장 높은 확률의 class를 맞혔는지 셉니다. NLL은 정답에 부여한 확률의 크기도 봅니다. Brier score는 확률과 정답 표시의 제곱 차이를 보는 또 다른 지표입니다. 같은 accuracy여도 확률의 확신 정도가 달라 NLL·Brier가 달라질 수 있습니다. 낮은 loss 하나가 좋은 보정, 일반화, 실무 효용을 모두 보장하지 않습니다.

서로 다른 tokenization, 평가 데이터, 문맥 길이, padding/mask 처리의 perplexity를 같은 조건인 것처럼 비교하지 않습니다. 학습에 사용한 데이터의 NLL과 별도 heldout 데이터의 NLL도 구분합니다.

## 자주 틀리는 부분

- `P(A|B)`를 `P(B|A)`로 읽고 집단의 기본 비율을 무시한다.
- 평균에서의 편차를 제곱하지 않아 양수·음수가 상쇄된다.
- `n`과 `n-1`을 이유 없이 바꾸거나 한 sample의 표본분산을 계산한다.
- 평균 로그와 평균 확률의 로그를 같은 것으로 취급한다.
- 정답 확률만 보고 accuracy를 확정한다. 다른 class 확률과 판정 규칙도 필요하다.

### R07 — 작은 기본 비율

부품 불량 비율 2%, 불량의 경고율 75%, 정상의 경고율 5%입니다. 경고가 실제 불량일 확률을 10,000개 표와 식으로 각각 구하세요.

<details>
<summary>R07 해설</summary>

불량 200개 중 경고 150개, 정상 9,800개 중 경고 490개입니다. `150/(150+490)=15/64=0.234375`. 식으로도 `0.02×0.75 / (0.02×0.75+0.98×0.05)`로 같습니다. 75%는 다른 방향의 조건부 확률입니다.

</details>

<a id="r08"></a>
### R08 — 두 가지 분산

`[2,4,6]`을 같은 확률로 뽑는 분포의 평균과 분산을 구하세요. 같은 세 값을 독립 표본으로 보았을 때 불편 표본분산도 구하고 두 결과가 다른 이유를 설명하세요.

<details>
<summary>R08 해설</summary>

평균 4, 제곱 편차 합은 `4+0+4=8`. 분포의 분산은 `8/3`, 표본분산은 `8/(3-1)=4`입니다. 전자는 주어진 분포 자체의 퍼짐, 후자는 표본 평균을 사용해 모집단 분산을 추정하는 통상적인 계산입니다.

</details>

<a id="r09"></a>
### R09 — NLL과 다른 지표

두 정답 token의 확률이 `0.25,0.5`입니다. 평균 NLL과 perplexity를 구하세요. 이 두 값만으로 top-1 accuracy도 알 수 있나요?

<details>
<summary>R09 해설</summary>

평균 NLL은 `(ln4+ln2)/2=ln(sqrt8)≈1.0397208`. perplexity는 `sqrt8≈2.8284271`입니다. 다른 class의 확률과 동률 처리 등을 주지 않았으므로 일반적으로 accuracy를 정할 수 없습니다. 분류 class 수에 대한 추가 조건도 없습니다.

</details>
