ENGINEERING FOUNDATIONS LAB / BROWSER SDK 2.47.2

정상 이벤트에서 진단·복구까지

개인 localhost·합성 데이터·허가된 테스트 프로젝트 전용입니다. 시작 전에는 SDK/CDN을 로드하지 않습니다. 회사 운영 키·실제 사용자 정보를 넣지 마세요.

1. 전송 대상과 허가 확인

별칭 확인은 실제 계정/키 소유권 검증이 아닙니다. SDK는 키를 메모리에서 사용하고, 이 앱은 입력·키·raw 응답을 로그/파일에 저장하지 않습니다. Network 화면에는 키가 보일 수 있습니다.

2. 정상 동작 → 관측 → 사건

기본: 로그인 A → Product Viewed → Checkout Started → Purchase Completed → flush → 프로젝트에서 동일 run 확인. 계측/분석의 정답은 문서에서 별도로 검산합니다.

새 track 호출 최대 20회·시작 후 5분, 자동 retry 0, 자동 계측/remote config/Replay/진단 telemetry off입니다. 메모리 저장만 사용하므로 새로고침·탭 종료 시 미전송 이벤트가 사라질 수 있습니다. 중지는 이미 queue에 있거나 전송 중인 이벤트를 취소하지 않으며, 이후 queue가 전송될 수 있습니다. 5분은 신규 작업 제한이지 네트워크 종료 시한이 아닙니다. 서버 데이터는 삭제하지 않습니다.

3. 정제된 로컬 실행 원장

여기의 callback/flush 결과는 chart 가시성·중복 제거·사용자 병합 성공을 증명하지 않습니다. DevTools Network와 테스트 프로젝트를 함께 확인하세요.

준비 상태: SDK 미로드, 외부 전송 없음.
